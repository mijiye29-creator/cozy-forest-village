문제점 · 해결 방법

구현과 검증 상태를 구분
수정 완료
읽음 저장
중간에 닫은 대화를 읽음 처리하던 문제를 수정. 비정상 읽음 저장값을 객체로 복구. 회귀 검사 통과.
자료 대기
인트로 이미지
어제 만든 네 이미지가 현재 저장소에서 확인되지 않음. 원본 위치를 확인한 뒤 연결하고 화면 QA. 다른 참고 이미지를 대신 쓰지 않음.
검증 필요
실제 기기
코드 검사와 브라우저 자동화는 iOS·Android 실기기 검증과 구분. 회전·앱 전환·저장·터치·보스까지 전체 진행을 확인해야 함.
다음 감독 지시

네 이미지 출처 확인·연결 → 인트로 시각 QA → iOS·Android와 보스까지 전체 진행 검증 → 출시 점검. 네 번째 마을은 작성한 구현 계획에 따라 저장·맵부터 진행합니다.
