# 포근한 숲속 마을

세 마을의 이야기를 따라 자원을 모으고, 일꾼을 성장시키고, 마을을 지키는 모바일 게임 프로젝트입니다.

## 현재 게임

- 실행 파일: [`game/index.html`](game/index.html)
- 조작: 지도에서 드래그해 이동하고, 강화 발판 위에 직접 올라서서 구매합니다.
- 진행: 숲속마을 → 호수마을 → 광산마을. 이전 마을 일꾼의 성장과 마을 복구를 마치면 다음 마을이 열립니다.
- 저장: 브라우저의 `localStorage`를 사용합니다. 브라우저/기기 사이 플레이 저장 데이터는 아직 동기화되지 않습니다.

## 개발

현재 게임은 단일 HTML 파일이며 빌드나 패키지 설치가 필요하지 않습니다. 코드 점검은 Node.js에서 `node tests/mobile-runtime.cjs`로 실행합니다. 게임 실행과 화면 확인은 `game/index.html`을 브라우저에서 엽니다.

`design/`에는 스토리와 콘셉트, 루트 JPEG에는 참고 이미지가 있습니다. `포근한 숲속 마을.html`은 가져온 원본 보관본입니다. 실제 개발 대상은 `game/index.html`입니다.
